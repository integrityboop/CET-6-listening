# CET-6 听力分节播放器

把 12 个完整听力录音按内容自动切分成 84 段，按 Section A/B/C 分层，可逐段精听。

- 在线使用：https://integrityboop.github.io/CET-6-listening/
- 电脑本地：双击 `启动.bat`（可导出音频），或直接双击 `CET-6 听力分节播放器.html`（仅播放）

分段依据：每题后有约 13.4 秒答题停顿，每卷 25 处，按 4/4/3/4/3/3/4 分组 = 7 段。

音频格式：mp3（单声道 40 kbps）。原先用的是 HE-AACv2 的 .m4a，手机自带浏览器解不开，故统一换成 mp3——安卓/iOS 所有浏览器都能直接播。换格式时已逐样本核对过与旧文件的时间轴对齐（差值在 0 ms 处最小），所以分段时间表没变。
